# Jujutsu Controller

プロジェクトを複数人で進める場合でGitを使えない人がリポジトリのファイルをいじりたいときに毎回Gitの解説をするのがとてもめんどくさいのでCLIベースで簡単にGitの操作ができるスクリプトを作成しました。

## 機能

このスクリプトには以下の機能が含まれています。

### 自動セットアップ

GitHubのユーザー名、メールアドレス、リポジトリURL（httpsでも公開鍵でも可）を入力することで自動で任意フォルダにcloneを行い即時作業を行える状態にします。

### 変更を確認（status / diff）

`jj status` `jj diff`

変更されたファイル一覧を表示し、一覧化されたファイルから選択することでファイル内の具体的な変更を確認することができます。

### 最新の情報を取得（fetch / rebase）

`jj fetch` `jj rebase`

リモートの更新をボタン一つで取得、現環境への上乗せを行います。

コンフリクトが発生した場合は後述の機能で解決することができます

### ブランチ操作（切り替え / 作成 / マージ / 削除）

`jj bookmark list` `jj bookmark create` `jj new` `jj bookmark set` `jj bookmark delete`

ブランチ操作メニューから、リポジトリのローカルbookmarkの切り替え、作成、マージ、削除を実行できます。切り替え・マージ・削除の前には確認が表示されます。

### 変更を保存（commit / push）

`jj commit` `jj push`

上記の「最新の情報を取得」を実行後、変更のpushを行います。コメントが設定されていない場合はコメントの設定を促します。

### 新しい変更で区切る（jj new）

`jj new`

コミットを区切ります。併せてコメントを設定できます。

### 変更にコメントを付ける（desc）

`jj desc -m ""`

過去のコミットを選択してコメントを設定することができます。コメントの上書きにも対応しています。

### 変更履歴を閲覧（log）

`jj log`

  最近10件までのログを表示します。

### 直前の操作を取り消す（undo）

`jj undo`

jj undoと同じ処理を行います。

### コンフリクトを解決（local / remote）

コンフリクトが発生した場合にローカルかリモートを選択してそのデータで上書きすることができます。

ファイル内の詳細な変更は実装していません。

### 保存済み設定を変更

初期セットアップ時に設定した設定を変更することができます。

### SSH署名鍵の登録

初期セットアップ時または「保存済み設定を変更」から、SSH公開鍵を署名鍵として任意で設定できます。公開鍵ファイルを読み込む方法と、公開鍵の文章を直接入力する方法に対応しています。ファイルを指定した場合も、ファイルパスではなく中身の公開鍵文字列を設定に保存します。設定すると Git と Jujutsu の SSH署名が有効になり、公開鍵がクリップボードへコピーされます。

GitHubで署名を検証するには、表示された公開鍵を [SSH and GPG keys](https://github.com/settings/keys) の「New SSH key」から **Key type: Signing Key** として登録してください。鍵を変更するときは設定画面で「SSH署名鍵」を選択し、解除するときは `D` を入力します。秘密鍵の内容はJujutsuControllerで読み取りません。

### 自動更新

GitHubの最新リリースのバージョン情報と現在のスクリプトバージョンを比較し、更新がある場合は更新案内を表示します。

## インストール方法

1. リリースから最新の`ZIP`ファイルをダウンロードします。
2. 任意のフォルダに解凍します。
3. `start.bat`を開き初期セットアップを開始します。

初期セットアップに合わせて以下のソフトが自動インストールされます。すでにインストールされている場合はインストールは行われません。

- [PowerShell 7](https://learn.microsoft.com/ja-jp/powershell/scripting/install/install-powershell-on-windows)

- [Git](https://git-scm.com/)

- [Jujutsu](https://docs.jj-vcs.dev/latest/install-and-setup/)

## 使い方

1. `start.bat`を起動してください。

2. 2回目以降の起動ではメニュー画面が表示されます。

3. メニュー画面から各機能を選択して使用してください。

## 初期設定をもう一度行う。

設定はメニューの「保存済みの設定を変更」から変更することができます。基本的にそちらをご利用ください。

`.setup-completed`を削除してください。
